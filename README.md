A dynamic football league simulation system built using Python, HTML, CSS, and Pandas.

This project simulates league standings, calculates team statistics, and displays the final results in a visually appealing web interface.
1. Features
2. Simulates football league standings

--> Calculates:
1.Points
2. Wins / Draws / Losses
3. Goal Difference
4. Win Probability
  1. Monte Carlo simulation support
  2. Team ranking generation
  3. Generates dynamic HTML tables
  4. Stylish frontend using CSS
  5. Background images and UI enhancements
